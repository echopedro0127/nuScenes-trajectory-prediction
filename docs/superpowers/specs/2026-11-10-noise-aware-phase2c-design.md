# Phase 2C：受约束运动候选

用户在Phase 2B明确的减速/低速失败与下一步后授权继续。新分支feature/noise-aware-motion，旧worktree保持不变。只用原fit/select开发窗口，不评价holdout，不引入传感器或重训上游。

## 候选与因果性

共享原三条件、三噪声seed、608窗口和七候选。重新从原始历史缓存生成同一观测包，新增三候选。仅支持完整2Hz无延迟流；历史也降质，算法接口只接收packet，不读未来标签。

三候选均以当前NIS-KF估计位置/速度为起点，保留该方向，不预测转弯：

- bounded_ca：取截至当前的最近四个滤波速度大小，以0.5s采样时间线性拟合加速度，裁剪到[-4,2]m/s²；沿当前方向积分。
- brake_stop：固定-2m/s²刹停，速度到零后保持停止位置，不倒退。
- hold_position：保持当前估计位置。

速度<0.1m/s时因方向不可靠，三个候选都保持当前位置。减速积分时间限制到v/(-a)，剩余时刻位移恒定；预测过去槽位使用当前位置，但评价仍只看原固定终点的未到时间点。所有常数在评价前固定，不做参数搜索。它们是运动学先验，不是新运动模型理论，也不是实际驾驶制动指令。

## 受控训练

扩展到10输出：保留原18→32→7随机初始化网络，另加32→3线性头，新头权重0、bias=-2，不加载旧训练权重。938名义参数。所有控制共用相同初始化；baseline7屏蔽新三头，沿用原七维softmax与求和，以便精确复现旧full。

四组：baseline7（原七）、plus_ca（原七+CA）、plus_stop（原七+刹停+保持）、all_motion（十个全部）。屏蔽候选权重严格零；名义容量相同，但有效输出/参数不同，初始激活比例也随开放候选改变。原18维特征不变，fit-only标准化、单训练seed2027、同批次顺序、20epoch/700更新、原Adam预算，无早停/按select选epoch。未来机动标签只用于分组，不重采样或加权减速组。

报告全部控制、三新单候选、旧17参照的ADE/FDE/jitter、所有机动组和平均权重。主要对比all_motion对baseline7；plus_ca和plus_stop帮助解释来源。必须检查普通噪声、转弯、高曲率代价；不承诺候选增加必然改善。
