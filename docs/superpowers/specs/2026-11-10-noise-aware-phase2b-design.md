# V2 Phase 2B：机动诊断、时间编码与候选移除

用户在Phase 2A结果及明确下一步后授权继续。本轮在feature/noise-aware-diagnostics独立worktree执行，保留原noise-aware-online源码/产物可复核，不重训上游、不改旧协议、不用holdout。

## 固定问题和对照

复用Phase 2A同一608条轨迹、三条件、三个噪声seed的候选/特征缓存。按旧配置low_speed<2m/s、转弯15度、高曲率45度、平均加减速1m/s²分组；标签只由GT离线生成用于评价，标签可重叠，不进入模型。每组报告真实轨迹数和log数，不能将噪声重复当独立样本。

五个新训练条件，均保留18→32→7网络和原20epoch/700步/单训练seed2027/同初始化同批次顺序/fit-only标准化，不早停、不据select调参：

1. full：重放Phase 2A创新量门控，所有特征、七候选不变；权重和指标应精确复现，作为实现校验。
2. motion_time：保留motion6，把covariance6换为t的1至6次幂（t=step/11），残差六通道全零。显式时间编码与协方差同宽，但编码基底不同，不能把两者差值解释为随机观测不确定性。
3. time_innovation：motion6+time6+原innovation6，检验显式时间条件下的残差增量。
4. physical_candidates：full特征不变，只允许CV/alpha-beta/KF/NIS-KF四个输出；其余logit置负无穷后softmax，权重严格为零。
5. no_map_candidate：full特征不变，只移除map输出，保留GRU/original。

候选移除保持输入特征一致，因此仍有地图覆盖率特征；这不是完全移除地图输入的实验。网络名义839参数不变，但输出可用性、有效参数量会改变，需要如实说明。不能把禁用候选替换为重复物理专家以保持输出数，那会改变混合先验。

同时证明Phase 2A的协方差输入可由固定更新步查表完全重建。保留旧十二策略作为参照，报告全部五种新条件以及机动组ADE/FDE/jitter。clean分组的NIS触发率只称模型残差报警，不直接认定为传感器异常误报；outlier源步4/8与其他更新分开诊断，事件标记不入模型。
