# V2 Phase 1：共享带噪观测流与滤波基线

日期2026-11-10，基于[近期调研](../../research/2026-11-09-nuscenes-literature-and-v2-directions.md)。用户授权制定方案并开始实验。

## 分阶段路线

1. 本轮：固定噪声/延迟/丢失流程，比较纯物理滤波基线，诊断是否值得增加协方差/创新量可靠性信息。不训练神经网络。
2. 后续独立阶段：重建带噪历史下的GRU/地图候选，加入协方差、观测年龄和归一化创新量的因果门控；同时控制候选、参数量、训练预算和可用观测。当前R反馈不是新方法，新增机制须有独立增量证据。
3. 再后续：更丰富CA/转弯候选、轻量因果状态记忆；按数据覆盖与资源决定真实图像/点云特征接入。不得把物理融合/在线聚合本身声称首创。

当前holdout已经评价，不再用其误差调参。本轮仅使用旧independent_fit/select作为开发数据，不建立新的泛化结论；不以改变split seed冒充新盲测。最终新结论需另留未参与新开发的数据。

## Phase 1固定协议

新分支feature/noise-aware-online，独立worktree。旧冻结源码、权重、结果不改。
数据只取metadata缓存中的历史/未来XY，源角色independent_fit和independent_select，按log分组后按SHA256("v2phase1:{role}:{instance}:{sample}")选择。
fit每log最多16轨迹，select每log最多64轨迹，稀少log不补抽；采样规则固定在误差计算前。三个噪声种子2027/2028/2029，不是三个模型训练seed。
固定2Hz、5历史点含t0、12未来点、11次更新和原始终点。历史和在线新增位置都降质，禁止保留干净历史给滤波器初始化。
每个包带source_step/available_step，只有available_step<=当前step才能进入算法。延迟时滤波状态保存在最近测量的source时刻，再外推到当前时刻，不把迟到测量误当当前位置；无新包时不重复同化旧测量。

固定9条件（XY独立高斯noise；偏置/离群方向按key确定，跨算法共享）：

| 条件 | sigma / m | 其他 |
| --- | ---: | --- |
| clean | 0 | 无 |
| noise_05 | 0.5 | 无 |
| noise_10 | 1.0 | 无 |
| noise_20 | 2.0 | 无 |
| noise_bias | 0.5 | 每轨迹固定2m方向偏置，历史/新增位置都加 |
| noise_outlier | 0.5 | 第4/8源时刻额外5m离群点 |
| noise_dropout | 0.5 | 第4/5/6源时刻丢包 |
| noise_delay_500ms | 0.5 | 全部历史/新增位置延迟1步 |
| noise_delay_1000ms | 0.5 | 全部历史/新增位置延迟2步 |

算法：raw_cv（最近两次已到位置差分）、alpha_beta（alpha0.6/beta0.2）、kf_cv、kf_nis。
共同从最早两次已到历史位置初始化位置/速度。KF状态[x,y,vx,vy]；连续白噪声加速度谱密度q=1，固定测量R=0.25I，不使用条件真实sigma作oracle调参。
初始P的位置块R、速度块2R/dt²、交叉块R/dt。KF用Joseph协方差更新；kf_nis仅在NIS>9.21时以min(25,max(1,NIS/9.21))膨胀R。
9.21作为2自由度99%卡方参考阈值固定，不假设真实车辆/注释误差完全服从该统计模型；稳健KF可能把真实机动误当离群，必须报告退化。
本轮条件不含乱序包；算法拒绝source倒退，后续另设计乱序处理。所有操作在固定局部坐标进行，估计器不读GT原点/未来标签来校正噪声。

## 输出与判读

按轨迹/条件/噪声seed/算法保存ADE/FDE/jitter、位置RMSE、第7/8更新恢复ADE；jitter沿用原完整序列定义。GT仅在评价函数可见。
计时仅在select、第一个噪声seed记录：每次已到包同化+当前状态外推+12点预测，排除包生成/历史初始化/指标/IO；报告p95及CPU环境，不与旧GPU在线p95直接比较。
保留按log/条件和噪声seed明细，条件等权总体仅为描述。没有CI显著性或测试集收益结论，不根据结果本轮重选q/R/阈值/采样。
本轮不比较旧RH：旧候选依赖干净历史与位置地图查询，直接混用会造成不公平及信息泄漏。需在下一阶段重建带噪候选后才可公平纳入。
不训练、不下载、不推送、不改简历，不修改旧holdout冻结链。
