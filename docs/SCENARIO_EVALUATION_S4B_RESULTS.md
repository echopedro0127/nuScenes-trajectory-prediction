# Phase 3A S4b：共用GT参考方向的纵向/横向误差

日期：2026-11-12。分支`feature/scenario-evaluation`，实现前HEAD为`182fc1d`。本轮完成M4纯指标及真实S2子集集成，不训练、不新增holdout评价，不作为S7正式全量成绩。

## 1. 解决什么问题

L2误差只说明位置差多大，不能区分沿行驶方向的外推失准和横向偏差。若各模型用自己的估计方向分解，又会在不同坐标系中比较。本轮新增`evaluation/directional_metrics.py`，所有模型使用同一GT当前/历史运动方向，模型预测不参与参考帧构建。

方向标签仅在离线评价层使用；不会把GT方向或未来运动标签补入模型输入。本阶段不能单凭方向分解认定某种失配是误差的唯一原因。

## 2. 时间、符号及有效性

- GT速度方向来自相邻0.5s位置段，历史5点、查询1至11。查询k只扫描截至该时刻的GT段，不读取未来方向。
- 速度>=0.5m/s（位移>=0.25m）更新方向；低速沿用此前最后可靠方向，padding mask阻断无效相邻段。
- 从未出现可靠方向时，该查询M4无定义；不借未来方向、固定agent yaw或模型方向补齐。
- 固定1s lead，k=1至10，数组row=k−1、目标列j=k+1。
- 误差`e=P−Y`；单位方向d，左法向`n=(-d_y,d_x)`。
- 纵向有符号误差为e·d，横向有符号误差为e·n；主要报告纵向/横向绝对误差及纵向有符号偏差。
- 正纵向表示相对GT偏向当前运动方向，负值表示反向偏后；正横向表示当前参考方向的左侧。不能将米制偏差直接解释为时间延迟。

低速沿用的方向是历史运动参考，并不证明静止车辆当前真实车身朝向。历史可靠段结束step可为−3至0；查询段为1至11，`source_steps=-999`仅表示无定义，必须结合valid_mask解释。

有效查询满足`hypot(longitudinal,lateral)=L2_error`。该关系逐点核验，不能把两个绝对误差均值的平方和当成平均L2。

## 3. 统计与不可评价

先对每窗口/noise重复中的有效查询平均，再对同窗口有效noise重复均权，最后对可评价窗口均权。没有有效方向的重复/窗口只从M4均值中排除，不删除已有M1/M2/M5记录。

同时报告全部/有效查询、全部/可评价观测流、全部/可评价窗口、noise seed数和覆盖率。JSON无可评价结果为null/status/reason；内部投影NaN必须带mask并只存NPZ，不能把无方向样本填0降低均值。空分组、无方向和完整性错误分别处理。

## 5. 子集诊断：有符号偏差不能单独排名

以下沿用既有对照，均为select/outlier、1s lead，门控训练seed2027；不挑最优seed。这组326条观测流、256个窗口、4log，共3,260个查询，其中3,174有方向、86无定义，256个窗口均至少有一个可评价查询。

| 策略 | 纵向绝对均值/m | 纵向有符号均值/m | 横向绝对均值/m |
| --- | ---: | ---: | ---: |
| Raw CV | 4.274907 | −0.057891 | 4.006750 |
| NIS-KF | 1.669245 | −0.169942 | 1.271918 |
| baseline7 | 1.662231 | −0.305474 | 1.231438 |
| plus_ca | 1.650658 | −0.296350 | 1.219684 |
| guarded_ca | 1.654778 | −0.298090 | 1.226246 |

Raw CV的有符号纵向均值更接近零，但纵向绝对误差明显更高，说明正负误差可能抵消；不能因为偏差接近零就认为更准确。门控在该子集的平均纵向偏差为负，只能描述在当前GT运动参考方向上偏后，尚不能认定真实制动、响应滞后或滤波机理是根因。

这里沿用S2不均衡条件邻域，尚未按机动标签、逐log和三训练seed完成正式全量分析。表中小差值不作为选模、显著性或新泛化提升证据；S4d标签及S6/S7仍待实施。

M4仅对方向有效查询计分，与S4a全查询误差/Miss的分母不同，不能直接将两阶段均值相减当作变化。
