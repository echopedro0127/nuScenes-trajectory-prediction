# 项目进度与改进汇总

更新日期：2026-11-25。项目：**基于nuScenes的因果在线轨迹预测与鲁棒修正**。

## 项目解决的问题

单次预测未来轨迹后，车辆仍会持续收到新增观测。本项目构建按约0.5 s释放观测的因果在线更新链路，在固定目标时间轴上修正未来轨迹，并评价精度、修订抖动、观测退化和恢复代价。新阶段进一步使用实际微秒时间戳，避免把所有更新都当作精确0.5 s。

项目已包含物理基线、GRU/轻量Transformer、残差修正、地图/上下文候选及可靠性融合探索。历史mini Radar实验实际读取过PCD；最新真实时钟/Gaussian/离群实验使用metadata派生XY与合成降质，两条证据不能混写成真实感知融合提升。

## 当前数值改进及代价

以下为**select开发验证角色、1 s提前量、窗口宏平均位置误差**。带噪条件先对同窗口三个观测噪声seed等权平均；clean仅一次。它们不是官方6 s ADE/FDE，也不是新的holdout结果。

| 条件/对照 | 原误差 / m | 改进后 / m | 变化 |
| --- | ---: | ---: | ---: |
| clean：CV fixed dt → actual dt | 0.711013 | 0.633016 | 降低10.97% |
| clean：KF fixed dt → actual dt | 1.024706 | 0.998683 | 降低2.54% |
| Gaussian 0.5 m：actual CV → KF | 2.400904 | 1.468641 | 降低38.83% |
| Gaussian 1.0 m：actual CV → KF | 4.596162 | 2.256338 | 降低50.91% |
| Gaussian+离群：actual KF → NIS-KF | 1.846843 | 1.684352 | 降低8.80% |
| 同一离群条件：query误差P95 | 5.672426 | 4.041296 | 降低28.76% |

重要负结果：clean下KF仍明显差于CV；1 m Gaussian下actual CV比fixed控制略差0.25%；NIS在clean和Gaussian-only下分别退化0.47%和0.54%。离群后k=1恢复事件子集里，NIS相对KF在三个seed都略差，均值差+0.064295 m。不能将条件化收益表述为全场景优越。

历史独立评估中，冻结RH在3,329轨迹/6 log、六条件等权holdout上的在线ADE/FDE相对CV降低5.41%/6.18%，同时jitter增加5.33%。该结果来自单模型seed、标注位置因果回放和既有数据重划分；与本轮真实时钟合成离群结果使用不同协议，不能合并或相加。该holdout已使用，后续不再作为未见调参数据。详见[历史holdout报告](CAUSAL_CONTEXT_INDEPENDENT_HOLDOUT_RESULTS.md)。

## 工程层面的改进

- **观测公平性**：同一源token共享扰动，重叠窗口不重新抽噪声；初始两点、暖启动和在线新增观测全部允许降质。
- **时间和真值隔离**：状态核只接收已到位置与时间，未来GT仅用于评价；带噪首观测作原点，不给算法额外干净定位。
- **可解释鲁棒更新**：固定q=1、R0=0.25I、NIS阈值9.21、R倍数上限25；大新息时降低测量权重，使用Joseph协方差更新，不事后搜索有利参数。
- **结果可重建**：源码/配置、父owner与输入引用绑定哈希，原owner验证父结果，completed最后写；支持语义重放、独立标量对照及保存预测重评分。
- **异常可追溯**：区分源清单、实际接收唯一源、窗口更新暴露及有效GT分母；保留空组、连续异常、窗口尾部和无GT原因。
- **验收证据**：B3b2b新增8个源码/入口文件、5个测试文件、33项测试，全套1289项通过；十个旧冻结owner源码与静态产物保全。

B3b2b本地冻结产物约1.12 GB，包含28组合的状态、协方差、预测与诊断；这不是独立数据量，也不会上传GitHub。正式生成耗时包含父验收和IO，不能作为车端延迟或FPS。

## 下一步为何研究恢复

父结果的只读分层发现：离群后首个正常包NIS报警率58.62%，同位置Gaussian-only对照1.38%；平均R倍数2.12，88.66%创新与前一次反向。排除初始化离群后报警仍有55.05%，提示问题不只来自初始状态。

候选规则只记忆前一次pre-update创新和NIS，在双报警、创新反向且幅值下降时将基础R scale从s缓和到sqrt(s)；设置恢复到1和去掉幅值约束的消融。候选开放环4574次触发中，93.99%在离群后首包，但5.64%仍是当前离群，因此必须正式闭环评估其收益与代价。

主方法及规则尚未实现；计划21组新预测和14个冻结父参考单元，重点比较k=1恢复误差、整体/尾部以及clean/Gaussian代价。没有新增数据下载、训练或新提升结论。
